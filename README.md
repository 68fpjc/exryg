# exryg.x

## これはなに？

X68000 版『アルゴスの戦士』ディスク中の *.RYG ファイルを解凍するプログラムです。黒歴史として公開します。

以下は、当時のアーカイブに同梱されていた exryg.doc です (一部修正してあります) 。

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

		     解析してたらこんなものができた
				exryg.x
			Copyright 1998 Igarashi

───────────────────────────────────
━━━━━
これは何？
─────
　電波新聞社「アルゴスの戦士」ディスク中の*.RYGファイルを解凍するプログ
ラムです。

━━━
使い方
───
　カレントディレクトリに「アルゴスの戦士」ディスク中のBOOT.X (不可視属性
がかかっていますが、ルートディレクトリに存在します) を置き、

	exryg <RYG ファイル名>

とすると、RYGファイルが解凍され、カレントディレクトリに 拡張子がbinのファ
イルができあがります。例えばRYGMAINL.RYGを解凍したい場合は、

	exryg RYGMAINL.RYG

とすると、カレントディレクトリにRYGMAINL.binというファイルができあがりま
す (RYGMAINL.RYGがカレントディレクトリにない場合はRYGMAINL.RYGの通過パス
も付加してください)。

　RYGファイル中、RYGMAINL.RYG、XDRV10L.RYG、XDRVL.RYG の３ファイルは、実
はＸ形式実行ファイルを圧縮したものです。これらはそれぞれ、

	RYGMAINL.RYG	メインプログラム
	XDRV10L.RYG	サウンドドライバ (10MHz専用)
	XDRVL.RYG	サウンドドライバ

となっています。これらを*.Xにリネームしてしまえば、コマンドラインやバッ
チファイルから直接実行できます。

━━━━━━━━━━━━━
解凍してなにがうれしいの？
─────────────
●disることができる

●HDDにインストールした時にちょっとうれしいかもしれない

	　SHIFT+DELキーでDOSに復帰できます。

━━
注意
──
●解凍にはBOOT.X内部の解凍ルーチンを使用しています。BOOT.Xは以下のものの
み対応しています。

	BOOT               X        45914  94-04-12  23:28:26

●入力ファイルが「アルゴスの戦士」用圧縮ファイルかどうかの検査はきちんと
行っていませんので、変なファイルを食わせないでください。

●PCMDATA.RYGは解凍できません (圧縮されていません)。

━━━━━━━━━━━━
HDD インストールについて
────────────
　まず、key_init.rを環境変数pathの通っているディレクトリへコピーしてく
ださい。

　適当なディレクトリを作り (以下、仮に、C:\RYGERとします)、「アルゴスの
戦士」ディスクから、以下のファイルをコピーします。

	BANKDATL.RYG
	BGDATAL.RYG
	FIXL.RYG
	MAINDATL.RYG
	OBJDATAL.RYG
	PCMDATA.RYG
	USADATAL.RYG

　次に、以下のファイルもコピーします。

	RYGMAINL.X	┐exryg.xで解凍した*.binを
	XDRV10L.X 	┘  *.Xにリネームしたもの

　そして、以下のようなバッチファイルを作成、実行すればOK (コピーチェッ
クがあるので、あらかじめマスターディスクをFD0に突っ込んでおいてくださ
い)。

	C:
	CD \RYGER
	XDRV10L
	RYGMAINL
	XDRV10L -R
	SCREEN
	KEY_INIT

　非10MHzマシンではXDRV10L.Xの代わりにXDRVL.Xを使用してください。

　さて、このままではSHIFT+DELでDOS復帰した際にテキスト画面に絵が残ってい
るので、KT.XなりCNCN.Rなりで消去しましょう。また、MPUキャッシュがOFFにさ
れてしまうので、必要に応じて再設定してください。

━━━━━━━━━━━
「スターフォース」も…
───────────

　「アルゴスの戦士」には、おまけとしてSRAMDBシステム対応「スターフォース」
が収録されています。「スターフォース」実行時には 「アルゴスの戦士」ディ
スク中の*.STFファイルが使用されますが、この*.STFファイルも、exryg.xで解
凍できます。

　解凍してできるファイルのうち、SFMAINL.binとSFBGML.binはＸ形式実行ファ
イルです。「アルゴスの戦士」同様、HDDインストールに挑戦すると…。

１：別配布のkey_init.rを環境変数pathの通っているディレクトリへコピーする

２：適当なディレクトリを作り (仮に C:\STFとします)、「スターフォース」ディ
スク (注：「アルゴスの戦士」ではありません) から、以下のファイルをコピー
する (すべて不可視属性がかかっていますが、ルートディレクトリに存在します)

	SPRITE
	BG
	BBG
	BBBG
	FRONT

３：２のディレクトリに以下のファイルをコピーする

	SFPCM.DAT	「アルゴスの戦士」ディスクからコピー
	SFBGML.x	┐exryg.xで解凍してできるSFBGML.binおよび
	SFMAINL.x	┘  SFMAINL.binをリネームしたもの

４：以下のようなバッチファイルを作成し、実行する (コピーチェックがあるの
で、あらかじめ「スターフォース」ディスクをFDDに挿入しておくこと)

	SUBST B: C:\STF
	B:
	CD \
	SFBGML
	SFMAINL
	SFBGML -R
	SUBST -D
	SCREEN
	KEY_INIT

━━━━━━
その他の注意
──────

係ですので、各社に対する問い合わせは御遠慮ください。

●例によって無保証です。各自の責任において使用してください。

●exryg.xはフリーソフトウェアとします。


						     Jan 1 1998 いがらし
```
